Deobfuscate a protected Luau script

Drop in a script, or paste it. The site identifies the obfuscator, lifts VM bytecode back to source where it can, and sandbox-traces the rest. Nothing is uploaded anywhere else and jobs are deleted after a few hours.

↓
Drop a .lua / .luau file or click to choose — or paste below

Only analyse scripts you own or have permission to inspect

This tool exists for security research and recovery: finding the backdoor in a free model, understanding a script running in your own game, getting your own lost source back. Deobfuscating someone else's protected script to steal or redistribute it is not that, and it is not what this is for. Uploaded scripts are executed in a sandbox with a fake Roblox environment — no network, no filesystem, no executor APIs — but treat every sample as hostile anyway.

      Setting these up on your own server
      
# patched Luau (luau + luau-ast) — needs git, cmake, a C++ compiler
python tools/build_luau.py

# Lune — only for full Luraph v14.x devirtualization
bash tools/install_lune.sh

# then run the site
pip install -r requirements.txt
python run.py            # http://0.0.0.0:8000

      
Or docker compose up --build, which does all of it in the image.
